# 按系列选片 · 2026-10-28

入口：`/admin/curation`，使用原管理员账号登录。后台与人像库均有「选片与清理」链接。页面和接口不接受匿名访问。

## 标记规则

- 不标记：保留原状态，保存其他照片时不会修改它。
- **0**：删除，保存后移入可恢复的回收站，公开页面停止展示。
- **1**：很好，保存为优秀作品标记；已公开且具备人像展示标签的作品可优先用于人像展示。
- 再点一次当前标记，或点清除，恢复不标记。回收站也可改为 1 或不标记来恢复；原本未公开的照片不会被自动发布。

标记先存入当前浏览器、当前账号的本机草稿。切换系列、刷新不会清掉草稿。点击「保存标记」才提交实际差异；含 0 的批次会列出待删照片再次核对。勾选框只指定批量标记对象，不会删除未勾选照片。没有反选删除或一键清空图库。

按系列浏览，每页最多 60 张，缩略图完整显示原比例。点击图片放大，左右键换图，0 / 1 标记并下一张，Backspace 清除。手机使用系列下拉框。当前索引包含 494 条数据库照片及 6 张旧版固定展示图，共 500 张、58 个逻辑系列；仅已公开的公开作品继续对访客展示。

## 数据与公开展示

`photo-curation-20261028.sql` 已应用到关联项目。私有 `app_private` 表记录审核、原发布状态、封面快照和旧版固定图；启用 RLS，只有服务端 service_role 能执行四个 RPC。浏览器通过验证管理员身份的 API 操作，不直接访问审核表。

保存是原子事务，只处理明确传入的 ID；精确比对照片与审核时间戳。其他页面更新过的照片返回 409，保留本机草稿，刷新后核对再保存。删除不移除数据库照片、标签、翻译或 R2 文件。系列封面自动换成仍公开的照片；空系列隐藏；完整恢复后还原原封面和发布状态。

数据库照片通过发布状态退出公开 API；静态副本按确切源路径与记录 ID 绑定，避免同名 DSC 文件跨系列误删。公开缓存仅包含隐藏 ID 与已允许公开的优秀人像，不序列化私人图库。保存后同时失效公开数据标签与布局缓存。

未撤下 Hongjia / Oeschinen，也没有替用户提交真实选片决定。
