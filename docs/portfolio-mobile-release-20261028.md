# 移动端检查与发布准备 · 2026-10-28

检查覆盖首页、作品集、照片浏览、人像照片书、约拍页、预约弹窗和简历。保留现有设计，本轮仅补了一处部署资源路径问题。

## 尺寸与观看

使用浏览器尺寸模拟：390×844、844×390、667×375、320×568。浏览器为桌面内置浏览器，非实体手机或 iOS Safari；可验证布局、图片资源、路由与操作，但不证明真机触摸、软键盘或 GPU 呈现帧率。

- 首页竖屏使用开发环境专用 `rotate=preview` 检查提示，横屏后提示消失。生产提示仍只对触摸手机显示，不强制锁定方向；尺寸模拟本身不会伪装成真实触摸手机。
- 横屏首页保留完整人物 / 花草构图、角落导航和看作品入口。点击首屏后滚动进入作品集可用。
- 首页、约拍首屏、照片浏览和简历所测尺寸的 document.scrollWidth 均不超过 viewport；桌面滚动条会占用约 15px，因此普通页面 CSS 可用宽度小于设置的窗口宽度。
- 人像照片书完成 1→2→1 双向翻页。独立过渡回归脚本确认旧图与目标图的深度交接、终点、取消过程保持一致。
- 作品浏览在横屏打开、切下一张、旋转为竖屏并从缩略图面板选择第 7 张，最终计数正确。图片 object-fit 为 contain，横 / 竖幅保留完整画面。
- 地图在靠近视口时加载；短横屏保留地图与地点并排布局。上一轮已验证公开地图关联数据与拖动，未重新设计地图。
- 预约弹窗在 390px 宽度下为 350px，左右各 20px；输入字体 16px。667×375 下可在弹窗内滚动到提交按钮、关闭弹窗；检查没有提交预约、发邮件或调用付费模型。
- 简历在 390×844 与 320×568 下检查标题、文字和按钮换行；没有观察到横向溢出。保留简历进入 Portfolio 的单向导航。

## 发布前修复

约拍的部分历史展示素材引用 `/private/*.jpg`。页面缩略图本来会映射到公开优化副本，但放大浏览仍请求未纳入 Git 的本地原图，线上会出现 404。现在光箱也解析到已选定的公开副本，不需要上传私人原始文件。

新增 `scripts/check-portfolio-assets.cjs`：检查 73 个本地展示资源确实纳入 Git 且文件名大小写匹配，并验证 5 个历史私人原图路径的光箱副本可随部署提供。已知公开原图与远程图片地址保持原有选择。

本地 `public/copy-review.html` 是文案新旧审阅页，保留本地文件并加入忽略规则，不发布到公开网站。环境文件、日志、构建缓存与私人目录也未纳入提交。

## 检查结果

- 独立 TypeScript 检查通过。
- 修复资源路径后，隔离目录的 Next.js production build 通过，无 Supabase fetch failed。主预览 3000 保留运行。
- Portrait 翻页回归、36 系列 / 420 照片双语文案检查、安全回归、本地部署资源检查全部通过。
- 暂存文件格式检查通过；对照本地 8 类已配置服务端密钥检查暂存内容，未发现密钥值。

Supabase 权限迁移与共享限额已在前一轮应用。官方仍有 8 条托管 PostGIS 与 2 条认证设置告警，详见 `supabase-security-audit-20261028.md`；此次发布不把它们标记为清零。发布结果以当前 PR、Vercel 部署及合并后在线复测为准。
