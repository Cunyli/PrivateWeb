# 流畅度与编辑式页面复查 · 2026-10-27

本轮以真实滚动和完整访问路径为准，取代只用镜头脚本与平均 RAF/s 判断体验的方式。原有相机人物、流动云、穿云衔接和作品照片保留。

## 已实现

- 首页滚动直接跟随浏览器，去掉额外 70ms 跟随滤波。几何缓存到 resize，滚动不触发 React 整页更新。
- 人物/草地的着色计算限制在实际区域，统一时间项只算一次；默认画布约 100 万像素，可自适应降级，保持显示回调节奏。摄影作品原图不受这项预算影响。
- 去掉后台缩略图集中预取和每图尺寸引起的画廊状态更新。专栏数据接近视口才加载。
- 横向轮播按完整副本距离循环，副本宽度模式一致；响应式图片路径作为缓存键，避免额外宽度参数制造重复 URL。
- 简历改为大字姓名、当前研究重点、可展开项目、经历和联系。删除依赖滚动的逐块长时间淡入；原有事实和项目链接保留。
- 约拍改为摄影首屏、一组精选样片、简短拍摄流程、套餐与预约、必要 FAQ。51 个图片元素减为 9 个；不再重复多组样片、介绍与地图。保留既有价格、交付、额外费用、隐私、取消和预约接口。
- 约拍首轮就渲染八个经过核对的精选图位置，API 更新保持数量与稳定 key，避免从两张扩成八张时把阅读位置推走。
- 约拍复用按需加载的弹性照片浏览器，支持方向键、拖动、Escape；预约表单仅出现一次，套餐直接联动。

## 实际采样

同一 in-app browser，1440×900，20 秒窗口。表格为回调间隔，不是屏幕实际呈现帧率。

| 页面 / 环境 | 滚动回调 P95 ms | 全窗口最长间隔 ms | 超过25ms的滚动间隔 | 输入队列 P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 首页，修改前开发模式 | 24.1 | 149.1 | 4 | 67.1 |
| 首页，修改后开发模式 | 10.4 | 158.7 | 1 | 63.1 |
| 首页，修改后生产模式 | 10.3 | 141.8 | 4 | 25.8 |
| 简历，修改前开发模式 | 10.4 | 33.1 | 0 | 35.2 |
| 简历，修改后开发模式 | 10.0 | 18.1 | 0 | 16.2 |
| 简历，修改后生产模式 | 10.2 | 17.1 | 0 | 16.3 |
| 约拍，修改前开发模式 | 10.3 | 100.9 | 6 | 0.2 |
| 约拍，修改后生产模式 | 10.2 | 18.6 | 0 | 16.0 |

首页输入路径相同。约拍旧版有初始滚动恢复偏移，新版页面更短，不能把该对比当成严格基准，更不能声称所有性能指标都改善。输入事件数量也不同。

首页完整生产加载窗口仍有约142ms极值，尚未由这个探针确定是加载、浏览器调度还是 GPU 呈现因素。没有宣称锁定60/120fps。图片解码维度估算不等于进程或GPU内存。

## 验证

- TypeScript、生产构建、diff whitespace 检查通过。生产构建位于独立临时副本，没有覆盖运行中的开发缓存。
- 浏览器检查：穿云到作品、真实作品点击与返回（y=1350，作品区可交互）、正常换片、详情抽屉键盘隔离、约拍 lightbox 方向键/拖动/关闭、套餐联动、空表单必填校验、简历详情与复制反馈。
- 390×650、320×650 和 844×390 视口排版检查；中英切换；没有观察到横向溢出，手机表单字体16px。这里不是实体手机测试。
- 没有提交真实预约、发送消息或发布网站。

普通访问没有采样循环。显式使用 `?audit=1` 才进行20秒测量并在隐藏 DOM 报告中冻结结果。结构化原始数据与方法限制见 [portfolio-interaction-review.json](portfolio-interaction-review.json)。
