# 首页接触关系与旧版文案恢复 · 2026-10-28

## 人物与花坡

此前人物和中景花坡使用不同的滚动缩放、位移和鼠标视差，人物会离开原来的座位；大幅、低频的花草 UV 位移又让整片地面像平板一样摆动。

现在人物与支撑他的中景共用相机变换和源坐标，发梢、衣摆继续独立响应阵风。草尖改成幅度更小、频率更细的局部扰动，接触区域抑制风动。脚边增加少量草尖遮挡与接触阴影。近景花草仍有独立景深，云海和直接揭开作品集的过渡保留。

沿用已有 WebGL 单通道合成和纹理，不增加视频解码器、纹理采样或 DOM 动画层，也不改变刷新节奏与自适应像素预算。

## 文案

撤回 Kimi 文案覆盖及其搜索匹配优先级；列表、分类 API、系列详情、搜索详情均恢复数据库中的作者标题、副标题和描述。改写前快照与当前公开数据库逐字段核对：36 个系列、420 张照片、72 条系列译文、840 条照片译文均无差异。

改写 JSON、读取辅助模块和对应检查脚本只保留作历史草稿；公开页面不再导入它们。此次未写入数据库，也未回退匿名客户端、发布状态和路径验证等安全修复。
