原生 Safari 的照片书单页准备 CPU 峰值曾观察到约 16ms，调整后一次观测为约 9ms；这不是严格控制的 A/B 基准。内置浏览器首次书页初始化仍观察到约 42ms、单页准备约 19ms；预热后的三次交替翻页统计见表，不能据此宣称首次初始化没有停顿。

## 结论与边界

主要交互在本机接近浏览器交付的刷新节奏。简历和约拍样本仍分别出现 54ms、33ms 的活跃间隔；首次书页初始化也仍有峰值，不能写成全站已经零掉帧。RAF 是主线程回调诊断，不是 GPU 呈现或物理屏幕 FPS；Safari 未提供 Long Tasks 统计，不能将不可用值当作没有阻塞。

普通浏览使用不带 paperSlow 的 `/portfolio`。paperSlow 仅在开发环境将翻页动画速度降到 0.3 倍，不是刷新率上限。
